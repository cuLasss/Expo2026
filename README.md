# Expo2026 - IF Rush

![Status](https://img.shields.io/badge/status-vitrine%20p%C3%BAblica-1f8a45)
![Tecnologia](https://img.shields.io/badge/feito%20com-JavaScript%20%2B%20Three.js-10243a)

**IF Rush** é um runner 3D de sessão curta criado para apresentar áreas da Informática em uma experiência rápida, visual e jogável. O projeto nasceu como uma proposta para banca/exposição, aproximando visitantes do universo do curso por meio de corrida, perguntas, ranking e interação direta.

![Preview do IF Rush](docs/if-rush-preview.png)

## Visão Geral

A ideia do jogo é simples: o jogador entra em uma corrida temática, coleta conteúdos sobre Informática, desvia de obstáculos e responde quizzes durante a partida. Em vez de uma apresentação parada, o IF Rush transforma a explicação do curso em uma pequena experiência interativa.

Este repositório público funciona como vitrine do projeto. Ele mostra a proposta, o visual e a intenção do jogo sem expor o código-fonte completo, histórico de desenvolvimento ou arquivos internos usados no backup privado.

## O Que O Jogo Propõe

- Apresentar conceitos e áreas da Informática de forma leve.
- Criar uma experiência rápida para eventos, feiras e exposições.
- Permitir partidas curtas, fáceis de entender e boas para demonstração.
- Usar ranking para estimular repetição e competição saudável.
- Misturar exploração visual, reflexo e perguntas educativas.

## Funcionalidades Do Projeto

- Runner 3D feito para rodar direto no navegador.
- Personagem customizável antes da corrida.
- Controles por teclado e toque.
- Obstáculos, coleta de itens e progressão de pontuação.
- Quizzes integrados ao fluxo da partida.
- Ranking local/online pensado para uso em evento.
- Assets locais para reduzir dependências durante apresentações.

## Tecnologias

- **JavaScript** para lógica principal do jogo.
- **Three.js** para renderização 3D.
- **HTML/CSS** para interface, menus e HUD.
- **Netlify Functions** para suporte ao ranking online.

## Sobre Este Repositório

O código-fonte completo está guardado em um repositório privado de backup. Esta vitrine pública existe para apresentar a ideia de forma limpa, organizada e segura, mantendo o projeto visível sem carregar o histórico antigo de commits.
